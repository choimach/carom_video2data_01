캐롬(3쿠션) 당구의 물리 - 기술에 대응하는 물리 법칙 정리
=====================================================
(자료: Han(2005) 캐롬 동역학, Mathavan et al.(2010) 쿠션 충돌 모델, Alciatore(Dr.Dave)
 당구 물리 자료, pooltool 물리 엔진 이론 문서 등 참고)
(관련 문서: ref/carom_spec.txt = 규격, ref/carom_rules.txt = 규칙,
             ref/carom_technic.txt = 기술. 본 문서는 technic 문서의 각 기술이
             "왜 그렇게 되는가"를 물리로 설명하고, 시뮬레이션 구현 근거를 제공한다.)

0. 표기와 기호
-----------------------------------------------------
  m      : 공의 질량            R      : 공의 반지름
  I      : 관성모멘트 = (2/5)mR² (균질 구)
  g      : 중력가속도 9.81 m/s²
  r, v   : 공 중심의 위치·속도 벡터
  ω      : 각속도 벡터 (ω_z = 수직축 회전 = 사이드 스핀의 "제자리 회전" 성분)
  k̂      : 테이블 상방 단위벡터
  u      : 접촉점(공 바닥)의 상대속도 = v + R (k̂ × ω)
  μ_s    : 공-라사 미끄럼 마찰계수      μ_r : 공-라사 구름 저항계수
  μ_sp   : 공-라사 제자리회전(스핀) 감쇠계수
  μ_bb   : 공-공 접촉 마찰계수          e_bb : 공-공 반발계수
  e_c    : 공-쿠션 반발계수             μ_c  : 공-쿠션 미끄럼 마찰계수
  α      : 컷 각도(수구 진행선과 두 공 중심선이 이루는 각)


1. 캐롬 고유의 기하·물성값 (대대 기준, spec 문서 참조)
-----------------------------------------------------
- 공: 지름 61~61.5mm → R = 30.5~30.75mm, 질량 m = 0.205~0.220kg(표준 0.210kg)
      재질 페놀수지(Aramith 등) → 반발계수가 높고 표면 마찰이 낮다.
- I = (2/5)mR² ≈ 0.4 × 0.21 × (0.0306)² ≈ 7.9×10⁻⁵ kg·m²
- 테이블 유효 면적: 1.422m × 2.844m (정확히 1:2), 다이아 간격 355.5mm
- 쿠션(레일) 높이 h = 37~38mm
  · 공 중심보다 위로 올라온 높이   ε = h - R ≈ 6.3~7.5mm ≈ 0.21~0.25 R
  · 공 지름 대비 쿠션 높이         h/2R ≈ 0.61 (포켓볼은 약 0.635)
  · 쿠션 접촉점의 각도             θ = arcsin(ε/R) ≈ 12~14도
  ※ 이 "중심보다 살짝 높은 접촉"이 캐롬 물리의 핵심이다. 쿠션이 공의 중심 위를
    때리기 때문에, 충돌 시 공은 아래로 눌리면서 회전이 진로에 직접 반영되고,
    당점(상/하/좌/우)에 따라 반사각이 크게 달라진다. 중심과 같은 높이라면
    회전이 반사각에 거의 영향을 주지 못한다.
  ※ 캐롬 쿠션이 포켓볼보다 상대적으로 낮게(0.61D) 설계된 것은, 공을 띄우지 않고
    회전을 진로로 바꾸는 데 유리한 조건을 만든다.
- 실전 속도 영역: 약한 샷 0.5~1.5 m/s, 보통 2~3 m/s, 강한 대회전 4~6 m/s


2. 라사 위에서의 단독 운동 (4가지 상태)
-----------------------------------------------------
공의 운동은 접촉점 상대속도 u = v + R(k̂ × ω)의 크기로 결정된다.

2.1 정지 상태
    v = 0, ω = 0 → 모든 상태량 불변.

2.2 제자리 회전(스핀 온리)
    v = 0, ω_z ≠ 0
        ω_z(t) = ω_z0 - (5 μ_sp g / 2R) t
        소멸 시각 t = 2R ω_z0 / (5 μ_sp g)
    - 접촉이 점이 아니라 미소 면적이기 때문에 생기는 현상. 물리적으로 엄밀한
      계수가 아니라 현상론적(phenomenological) 계수로 다룬다.

2.3 구름(rolling) 상태 : u = 0
        v(t) = v0 - μ_r g t          (진행 방향 감속)
        ω(t) = v(t)/R                (자연 구름 조건)
        ω_z(t) = ω_z0 - (5 μ_sp g / 2R) t   (사이드 스핀은 별도로 감쇠)
        정지 시각 t = |v0| / (μ_r g),  이동거리 s = v0² / (2 μ_r g)
    - 구름은 "평형 상태"다. 미끄럼 마찰이 항상 공을 구름 상태로 끌고 간다.
    - 시스템 계산(파이브앤하프 등)이 성립하는 조건이 바로 이 안정된 구름 상태다.

2.4 미끄럼(sliding) 상태 : |u| ≠ 0
        u(t) = (u0 - (7/2) μ_s g t) û0          ← 방향 û0은 변하지 않는다
        v(t) = v0 - μ_s g t û0
        ω_xy(t) = ω_xy0 + (5 μ_s g / 2R) t (k̂ × û0)   ← 마찰 토크 부호
        미끄럼 종료 시각 t = 2 u0 / (7 μ_s g)
      (검증: 위 세 식을 u = v + R(k̂ × ω)에 대입하면 정확히 u(t) = u0 - (7/2)μ_s g t û0
       가 나와야 한다. 부호를 반대로 두면 u가 발산하므로 구현 시 반드시 확인할 것.)
    ★ 중요한 귀결: 미끄럼 구간에서 마찰력의 방향이 일정하므로 가속도가 일정하고,
      따라서 궤적은 정확히 "포물선"이 된다. 미끄럼이 끝나는 순간부터는 직선 운동이다.
      → 커브 샷/마세(technic 9장)의 곡선 진로가 바로 이 포물선 구간이며,
        "커브는 미끄럼이 끝나면 멈춘다"는 현장 경험과 정확히 일치한다.
    ★ 계수 7/2, 5/2는 균질 구의 관성모멘트 (2/5)mR²에서 유도된 값이다.


3. 큐 임팩트 (팁 → 수구)
-----------------------------------------------------
3.1 당점과 초기 회전
    중심에서 b만큼 떨어진 지점을 치면(팁 접촉 시간 ~1ms 미만, 충격량 근사):
        선운동량   m v = J
        각운동량   J b = I ω = (2/5) m R² ω
        ∴  ω = 5 b v / (2 R²)
    - 자연 구름(미끄럼 없음) 당점:  ω = v/R  →  b = (2/5) R = 0.4R
      즉 중심에서 위로 공 반지름의 40%(= 지름의 20%) 지점.
    - 상단 당점(b > 0.4R): 처음부터 과회전 → 앞으로 밀리는 밀어치기(팔로우).
    - 중앙 당점(b = 0): 미끄럼 구간 발생 → 스턴/정지타 영역.
    - 하단 당점(b < 0): 역회전 상태로 출발 → 적구 충돌 시 뒤로 끌리는 끌어치기(드로).
    - 미스큐 한계: |b| ≲ R/2. 이 범위를 넘으면 팁이 미끄러진다("반팁 법칙").
    - 캐롬 팁 지름 11~12mm는 R(≈30.6mm)의 약 1/3로, 유효 당점 영역을 3~4단계
      (1~4팁)로 나누어 쓰는 현장 관행과 맞는다.

3.2 스쿼트(디플렉션)
    - 횡회전을 주면 큐 축과 공 중심이 어긋나 팁이 공을 옆으로 밀고, 반작용으로
      큐 끝(엔드매스)이 튕기면서 수구가 겨냥선의 반대쪽으로 출발한다.
    - 크기: 큐에 따라 약 0.5~2.3도 (Shepard). 회전량과 엔드매스에 비례하고
      "샷 속도와는 거의 무관"하다.
    - 큐 끝 15~20cm의 질량이 지배적이므로, 얇은 샤프트·가벼운 팁이 스쿼트를 줄인다.

3.3 스월브(커브)와 합성 편차(squerve)
    - 큐를 세우거나 사이드를 주면 미끄럼 구간에서 궤적이 휜다(2.4의 포물선).
    - 스월브는 큐 세움각·회전량이 클수록, 라사가 무겁고 샷이 느릴수록 커진다.
    - 스쿼트(즉시 발생, 속도 무관)와 스월브(누적, 속도 의존)는 서로 반대 방향이라,
      특정 속도·거리·세움각 조합에서는 두 효과가 상쇄되어 겨냥선대로 간다.
    - 실전 대응: technic 2장의 "이론값 + 개인 보정" 원칙이 여기서 나온다.


4. 공-공 충돌
-----------------------------------------------------
4.1 이상 모델(무마찰·탄성)
    - 충격량은 두 공의 중심선(법선) 방향으로만 작용한다.
        제1적구:  v_OB = v0 cos α       (중심선 방향)
        수구:     v_CB = v0 sin α       (접선 방향)
      두 출구 방향은 서로 직교 → "90도 규칙"
    - 각속도는 이상 모델에서 변하지 않는다(회전은 그대로 유지).
    - 이 근사는 스턴(미끄럼) 상태 충돌에서 매우 잘 맞는다.

4.2 실제 모델(비탄성 + 마찰)
    - 반발계수 e_bb ≈ 0.92~0.96 (페놀수지 공, 통상 0.93을 표준값으로 사용)
      → 정면 충돌 시 수구는 완전히 멈추지 않고 조금 따라간다.
    - 접촉 마찰 μ_bb ≈ 0.05~0.10 (깨끗한 공 기준 0.06 부근)
      → 스로우(throw)와 회전 전달이 발생한다.

4.3 스로우(throw) - 실측 경향값
    - 컷 유발 스로우(CIT): 컷 각도 30~35도(대략 1/2 두께) 부근에서 최대 약 5~6도.
      10도 컷에서는 약 1.5도. 느린 샷일수록 크고, 빠를수록 작다.
    - 회전 유발 스로우(SIT): 스턴 + 중간 정도(약 50%) 사이드에서 최대.
      회전 방향이 접촉면 상대 미끄럼을 정확히 상쇄하는 "기어링(gearing)" 조건에서는
      스로우가 0이 된다.
    - 크기 감각: 최대 스로우는 적구 진행 1피트당 약 1인치(≈5도).
    - 상단/하단 회전(종회전)은 스로우를 최대 75%까지 줄인다.
    ★ 캐롬 함의: 얇게 치는 비껴치기(technic 5.6)일수록 스로우·스쿼트 오차가
      결과를 좌우한다. 두께가 회전보다 재현성이 높다는 볼값 시스템의 원칙
      (technic 6.5)은 이 마찰 민감도에서 나온다.

4.4 충돌 후 수구 진로 - 30도 규칙
    - 굴러가는(자연 구름) 수구가 1/4~3/4 두께로 적구를 맞히면, 접선 방향으로
      튄 뒤 남아 있는 종회전 때문에 진로가 다시 휘어, 결국 원래 진행 방향에서
      약 30도 벌어진 방향으로 정착한다.
    - technic 1.1의 경험적 분리각표(1/2 두께 55~60도 등)는
      "스턴 상태의 90도 규칙"과 "구름 상태의 30도 규칙" 사이의 실전 중간값이다.
      즉 당점(종회전량)이 분리각을 바꾸는 물리적 이유가 여기에 있다.

4.5 회전 전달
    - 접선 마찰로 제1적구에도 약간의 회전이 전달된다(수구 회전의 수 % 수준).
    - 프로즌(붙은 공) 상태에서는 충격량이 접촉선을 따라 즉시 전달되므로,
      규칙상 진행 방향 제한(rules 7장)과 함께 "밀어내기 파울" 판정 문제가 생긴다.


5. 공-쿠션 충돌 (캐롬 물리의 핵심)
-----------------------------------------------------
5.1 왜 어려운가
    - 쿠션은 고무(변형체)이고 접촉점이 공 중심보다 위(1장 참조)에 있어,
      법선 반발 + 접선 마찰 + 회전 결합 + 쿠션 변형이 동시에 일어난다.
    - 시뮬레이션에서 가장 부정확하게 모델링되는 부분이며, 3쿠션 시스템 보정의
      대부분이 결국 이 충돌의 비선형성 때문에 존재한다.

5.2 대표 모델
    (a) Han (2005) 모델 - 캐롬/3쿠션 동역학을 다룬 연구에서 제시.
        쿠션 접촉각 θ = arcsin(ε/R)을 도입해 3차원 충격량을 계산.
    (b) Mathavan et al. (2010) - 강체 쿠션 가정하에 충돌 중 미분방정식을 수치 적분.
        · 실험 정합값: e_c ≈ 0.98,  μ_c ≈ 0.14
        · 강체 쿠션 가정이 유효한 한계: 법선 방향 입사속도 약 2.5 m/s 이하
        ★ 즉, 강하게 친 샷(법선속도 2.5 m/s 초과)에서는 쿠션이 실제로 크게 변형되어
          모델(그리고 시스템 수치)에서 벗어난다. technic 6.1의
          "세게 치면 짧아진다"는 보정 규칙의 물리적 근거가 바로 이것이다.

5.3 계산 절차(Han 계열, 구현용)
    입력: 충돌 직전 v, ω, 접촉각 θ, 계수 e_c, μ_c
        s_x = v_x sinθ - v_y cosθ + R ω_y
        s_y = -v_y - R ω_z cosθ + R ω_x sinθ
        c   = v_x cosθ
        P_zE = m c (1 + e_c)                 (탄성 충격량)
        P_zS = (2m/7) √(s_x² + s_y²)         (미끄럼 소멸에 필요한 충격량)
    분기: P_zS ≤ P_zE (충돌 중 미끄럼이 멈추는 경우)
        v_x' = -(2/7) s_x sinθ - (1 + e_c) c cosθ
        v_y' =  (2/7) s_y
        v_z' =  (2/7) s_x cosθ - (1 + e_c) c sinθ
      P_zS > P_zE 인 경우(끝까지 미끄러지는 경우)는 μ_c를 사용하는 별도 식 적용.
    각속도 갱신(I = (2/5)mR²):
        ω_x' = -(mR/I) v_z' sinθ
        ω_y' =  (mR/I) (v_x' sinθ - v_z' cosθ)
        ω_z' =  (mR/I) v_y' cosθ

5.4 실전 현상의 물리적 해석 (technic 1.4 / 5.10과 대응)
    - 순회전(러닝 잉글리시): 접촉점의 접선 상대속도를 줄이는 방향 → 마찰 손실 감소,
      접선 속도 유지 → 반사각이 길어진다(벌어진다).
    - 역회전(리버스/체크): 접선 상대속도를 키워 마찰 임펄스가 반대로 작용 → 짧아진다.
    - 강한 샷: 쿠션 압축이 커지고 접촉 시간이 길어져 유효 반발이 떨어지고 각이 꺾인다.
    - 상단 당점: 충돌 시 아래로 눌리는 성분과 결합해 쿠션에 "무겁게" 물려 짧아진다.
      하단 당점: 튀어 오르는 성분이 생겨 상대적으로 길어진다.
    - 회전 감쇠: 매 쿠션마다 접선 마찰로 사이드 스핀이 상당 부분 소모된다.
      따라서 3쿠션 결과를 결정하는 것은 "1쿠션에서 준 회전"이 아니라
      "3쿠션 시점에 남아 있는 회전"이다(technic 1.2와 동일한 결론).
    - 에너지 손실: 쿠션 1회당 운동에너지의 대략 10~40%가 손실된다(입사각·회전 의존).
      대회전에서 세기가 아니라 "긴 팔로우스루로 회전을 오래 살리는" 타법이
      유리한 이유다.


6. 라사(천)와 환경
-----------------------------------------------------
- 캐롬 라사는 무결(worsted, Simonis 계열) 원단이라 나사결 방향성이 거의 없다.
  포켓볼/스누커용 기모(nap) 천처럼 방향에 따라 진로가 휘는 효과는 무시할 수 있다.
- 구름 저항 μ_r ≈ 0.005~0.015. 값이 작을수록(새 라사, 히팅 테이블) 공이 멀리 가고
  진로가 길어진다 → 시스템 수치가 길어지는 보정 필요.
- 습도가 높으면 실질 μ_r, μ_s가 커져 진로가 짧아지고 회전 감쇠도 빨라진다.
- 공 표면에 초크 가루가 쌓이면 μ_bb가 커져 스로우가 커진다(두께 감각 변화).
- 정지 판정: 실전 계산에서는 v < 1~5 mm/s 정도를 정지로 처리한다.


7. 기술별 물리 요약 (technic 문서 대응표)
-----------------------------------------------------
technic 항목            | 지배 물리
------------------------|--------------------------------------------------------
밀어치기(팔로우)        | b > 0.4R → 과회전, 충돌 후 접선 방향 + 잔존 종회전으로 재가속
끌어치기(드로)          | b < 0 → 역회전 잔존, 충돌 후 마찰이 뒤로 끄는 임펄스로 작용
정지타(스톱)            | 충돌 시점에 u ≈ 0이 아닌 스턴 상태 → 90도 규칙, 접선 성분 0
잽/짧은 스트로크        | 회전은 주되 v를 낮춤 → 쿠션 법선속도 감소, 각이 짧아짐
롱 팔로우스루           | 같은 v에서 회전량 확보 → 3쿠션까지 회전 잔존 → 길어짐
뒤/앞/옆돌리기          | 두께 → 분리각(4.4), 회전 → 쿠션 반사각(5.4)의 2단 결합
대회전                  | 총 에너지 예산 문제. 쿠션당 손실(6장) + 구름 저항 누적
리버스/짧은각           | 접선 임펄스의 부호 반전(5.4)
비껴치기(얇게)          | 스로우·스쿼트 민감도 최대(4.3), 회전 잔존량이 결과 지배
걸어치기(쿠션 먼저)     | 쿠션에서 회전이 재정의된 뒤 공-공 충돌 → 두 모델의 직렬 결합
마세/커브               | 미끄럼 구간의 포물선 궤적(2.4). 큐 세움각이 ω_z와 아래 방향
                        | 성분을 동시에 키운다
더블쿠션                | 낮은 법선속도 + 역회전으로 반사각을 극단적으로 꺾음
키스(쫑)                | 동역학이 아니라 "운동학(시간·경로 교차)" 문제.
                        | 두께로 제1적구 속도를, 세기로 통과 시간을 바꿔 회피한다


8. 계산 시스템의 물리적 근거와 한계
-----------------------------------------------------
- 왜 파이브앤하프 같은 "덧셈/뺄셈" 시스템이 성립하는가
  · 당점(2~3팁 순회전)과 스트로크를 고정하면, 각 쿠션에서의 반사 규칙이
    거의 동일한 함수로 반복된다.
  · 그 조건에서 출발점-1쿠션-3쿠션의 관계가 좁은 각도 범위에서 근사적으로
    선형이 되고, 다이아 좌표(등간격 355.5mm)를 쓰면 단순 합/차 관계로 표현된다.
  · 즉 시스템은 물리 법칙이 아니라 "고정 조건에서의 1차 근사 회귀식"이다.
- 왜 보정이 필요한가
  · 속도 의존 쿠션 반발(5.2의 2.5 m/s 한계) → 세기 보정
  · 쿠션마다의 회전 감쇠 비선형성 → 각도 영역별 보정
  · μ_r, μ_s의 환경 변화 → 테이블·날씨별 보정
  · 스쿼트/스월브의 개인차 → 큐·타법별 보정
- 결론: 시스템 값은 "기준선"이고, 실전 정확도는 보정 능력에서 나온다.


9. 시뮬레이션 구현 가이드
-----------------------------------------------------
9.1 아키텍처
    - 권장: 이벤트 기반(event-driven) + 해석해(analytic evolution).
      2장의 식들이 닫힌 형태이므로, 상태를 시간 적분하지 않고
      "다음 이벤트 시각"까지 정확히 점프시킬 수 있다.
    - 이벤트 종류: 상태 전이(미끄럼→구름→정지), 공-공 충돌, 공-쿠션 충돌.
    - 절차: ① 모든 이벤트 후보 시각 계산 → ② 최소 시각 선택 → ③ 그 시각까지
      해석해로 전진 → ④ 해당 이벤트 해석(충돌 모델 적용) → ⑤ 반복.

9.2 충돌 시각 계산
    - 위치가 시간의 2차 다항식이므로,
      · 공-공: |r_i(t) - r_j(t)| = 2R  →  4차 다항식의 최소 양근
      · 공-쿠션: 직선까지의 거리 = R   →  2차 다항식의 최소 양근
    - 수치 안정성: 근이 0 근처일 때의 재충돌(chattering)을 막기 위해
      최소 시간 간격(ε_t) 또는 접근 속도 부호 검사를 둘 것.

9.3 캐롬용 권장 초기 파라미터
    R          = 0.03065 m          (지름 61.3mm)
    m          = 0.210 kg
    I          = (2/5) m R²
    μ_s        = 0.15 ~ 0.25        (기본 0.2)
    μ_r        = 0.006 ~ 0.012      (기본 0.010, 고속 라사는 낮게)
    μ_sp       = 0.01 ~ 0.05        (현상론적 계수. 제자리 회전 지속시간으로 튜닝)
    e_bb       = 0.92 ~ 0.96        (기본 0.93)
    μ_bb       = 0.05 ~ 0.10        (기본 0.06)
    e_c        = 0.80 ~ 0.98        (Mathavan 실험값 0.98, 저속·강체 가정 기준.
                                     실전 감쇠를 맞추려면 속도 의존 함수로 낮출 것)
    μ_c        = 0.10 ~ 0.20        (기본 0.14)
    ε(쿠션)    = h - R ≈ 0.0065~0.0075 m (≈ 0.22R), θ = arcsin(ε/R) ≈ 13도
    테이블     = 1.422 × 2.844 m, 다이아 간격 0.3555 m
    정지 임계  = |v| < 0.002 m/s, |ω| < 0.05 rad/s
    ※ e_c를 상수로 두면 강한 샷이 실제보다 길게 나온다. 법선 입사속도 2.5 m/s를
      기준으로 감소하는 함수(예: e_c(v_n) = e0 - k·max(0, v_n - 2.5))를 두면
      "세게 치면 짧아진다"는 실전 특성이 재현된다.

9.4 검증 벤치마크 (구현 정확도 확인용)
    ① 90도 규칙: 중앙 당점 스턴으로 1/2 두께 → 두 공의 분리각 ≈ 90도
    ② 30도 규칙: 자연 구름 상태로 1/4~3/4 두께 → 수구 최종 편향 ≈ 30도
    ③ 자연 구름 당점: b = 0.4R로 치면 미끄럼 구간이 0에 수렴
    ④ 스로우: 1/2 두께 느린 샷에서 적구 편향 ≈ 5도 내외
    ⑤ 파이브앤하프: 수구수 50(코너) → 1쿠션 30 → 3쿠션 20 진로 재현
       (2~3팁 순회전, 중간 세기 조건에서 ±반 포인트 이내)
    ⑥ 코너 to 코너 무회전 뱅크: 대각 진로의 좌우 대칭성
    ⑦ 회전 감쇠: 3쿠션 통과 후 사이드 스핀 잔존량이 실전 감각과 맞는지
    ※ ①~④가 맞아야 공-공 모델이, ⑤~⑦이 맞아야 쿠션 모델이 신뢰할 수 있다.

9.5 자주 하는 실수
    - 쿠션을 단순 거울 반사(입사각=반사각)로 처리 → 회전 효과가 사라져
      3쿠션 게임 자체가 성립하지 않는다.
    - 공-공 충돌을 항상 무마찰로 처리 → 스로우가 없어 얇은 샷 결과가 어긋난다.
    - ω_z(사이드)를 진행에 반영하지 않음 → 쿠션에서만 쓰고 라사 감쇠를 빼먹으면
      대회전 계열이 과도하게 길어진다.
    - 미끄럼→구름 전이를 무시하고 항상 구름으로 처리 → 커브·끌어치기가 사라진다.
    - 단위 혼용(mm/m, deg/rad)과 팁 오프셋 b의 부호 규약 불일치.
